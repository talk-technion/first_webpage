# The Steppe Hall

A responsive, Mongol-inspired static game hall built with plain HTML, CSS, and JavaScript. It has no build step or external dependencies.

## Play locally

Open `index.html` in a modern browser.

## Games

- **Sudoku:** Each new puzzle is generated with a unique solution. Enter numbers with the keyboard or number pad, erase entries, and check your board.
- **Four Winds Whist:** A four-player partnership game. South is the human player; North, East, and West have distinct AI styles. Follow suit when possible, and score one point for each trick above six. The first partnership to seven points wins a game.

## Publish

The GitHub Pages workflow deploys the site from `main` whenever changes are pushed. The project site is available at <https://talk-technion.github.io/first_webpage/>.
