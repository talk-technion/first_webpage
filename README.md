# AI_ABOLISHER

A human-directed, AI-assisted retro-web outpost with terminal colors, original local SVG art, Sudoku, and four-player Whist. Its anti-AI voice is intentionally satirical. No build step, external fonts, or runtime dependencies are required.

## Play locally

Open `index.html` in a modern browser.

## Games

- **Sudoku:** Each new puzzle has a unique solution. Enter numbers with the keyboard or number pad, erase entries, and check the board.
- **Four Winds Whist:** South is the human player; North, East, and West have distinct AI styles. Follow suit when possible. A team scores one point per trick above six; the first to seven points wins a game.

## Satirical news feed

The rotating headlines are deliberately fictional comedy, not real reports or claims about actual systems.

## Publish

The GitHub Pages workflow deploys updates from `main` to <https://talk-technion.github.io/first_webpage/>.
